Module Library

Every BOSS module, in one place.

Each module is its own operating system, built from a few standard pieces. Open any piece below. Teach and The OS are the core of every module; workbooks, checklists, and assessments appear when a module has them.

How this library is organized

One manifest is the source of truth. The hub renders whatever it lists, so adding a module is an edit, not a rebuild.

boss/ ├─ index.html the hub (this page) ├─ modules.js the manifest ← edit this to add a module ├─ boss.css shared brand for every piece ├─ boss-gate.js shared BOSS2026 access gate ├─ _template/ copy this to start a new module └─ <module-id>/ one folder per module ├─ teach.html core ├─ os.html core ├─ workbook.html optional ├─ checklist.html optional └─ assess.html optional

To add a module:

  1. Duplicate boss/_template/ to boss/<your-module-id>/.
  2. Fill in the pieces you need (leave out the ones you don't).
  3. Add a block to modules.js pointing each piece at its file and set its status.

Every piece links ../boss.css and ../boss-gate.js, so it inherits the BOSS brand and unlocks with the same code. Existing modules can keep their current URLs, the manifest just points to them.
