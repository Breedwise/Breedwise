CC360 Workflow Build

The exact HighLevel/CC360 workflows that run the Tool → TPB → BOSS funnel: triggers, steps, waits, conditions, and goals. Build these five workflows in order. They pair with the funnel buildout and the 5 opt-in emails already created.

Before you build (prerequisites)

  • Pipeline: create Tool → TPB → BOSS with stages: Tool Opt-in · Tool Completed · Setter Working · Connected · TPB Member · BOSS Opportunity · BOSS Member · Nurture · Not a Fit.
  • Tags: confirm the tools fire litter-scorecard-optin / pb-scorecard-optin / science-scorecard-optin and the …-complete pair. Create tool-lead, tool-contacted, no-answer-1, tpb-member, boss-opportunity, boss-member, tool-nurture-monthly, not-a-fit.
  • Email assets: load the 5 opt-in emails (Email 1–5) as CC360 email templates; swap [Tool], [RESULT_LINK], [BOOK_CALL_LINK], [TPB_LINK].
  • SMS assets: the 4 setter texts (S1–S4) from the buildout; include Reply STOP to opt out on S1.
  • Sending: provision the SMS number; set a booking calendar for [BOOK_CALL_LINK]; set the owner user (Regina) and her notification channel.
Do this first: have each tool's opt-in edge function also add a single tool-lead tag, so one workflow triggers for every tool. Until then, set the WF-1 trigger to fire on any of the three opt-in tags (OR condition). I can make the function edit on request.

The five workflows

WF-1

Tool Lead Intake + Nurture

TriggerContact Tag Added = tool-lead  (or ANY of the three opt-in tags, until tool-lead is standardized)
  1. PipelineCreate/Update Opportunity → pipeline Tool → TPB → BOSS, stage Tool Opt-in.
  2. AssignAssign owner = Regina (or add owner-regina).
  3. NotifyInternal notification → Regina: “New tool lead: {{contact.name}} · [tool] · [source]. Call within 15 min.”
  4. TaskCreate task → Regina: “Call {{contact.name}} — new tool lead,” due +15 min.
  5. If/ElseHas phone number? → if yes, continue SMS steps; if no, skip to step 8.
  6. Wait5 minutes.
  7. Send SMSS1 — results ready + “I'll call you,” with Reply STOP.
  8. Send EmailEmail 1 (instant).
  9. Waituntil Day 1.
  10. If/ElseHas a …-complete tag? → No: Send SMS S2 (finish your tool). → Yes: skip.
  11. Send EmailEmail 2.
  12. Waitto Day 2 → Send Email Email 3.
  13. Waitto Day 4 → Send Email Email 4.
  14. Waitto Day 7 → Send Email Email 5.
  15. Add Tagtool-nurture-monthly (hand to long-term nurture). End.
Goal / Exit   Tag tpb-member added → jump to End. (WF-5 also removes the contact from this workflow.) Also stop on unsubscribe.
WF-2

Tool Completed (hot)

TriggerContact Tag Added = litter-scorecard-complete OR pb-scorecard-complete OR science-scorecard-complete OR tpb-scorecard-complete
  1. PipelineMove Opportunity → stage Tool Completed.
  2. NotifyInternal notification → Regina (hot): “{{contact.name}} COMPLETED [tool] — CALL NOW.”
  3. TaskCreate high-priority task → Regina: “CALL NOW — {{contact.name}} completed [tool],” due now.
  4. Wait3 minutes.
  5. Send SMSS3 — “saw you finished, want me to walk your top 3 moves?”
Goal / Exit   Tag tpb-member → End. Runs in parallel with WF-1; WF-1's Day-1 branch checks the same completion tag so no one gets double-asked.
WF-3

No-Answer Call Cadence

TriggerContact Tag Added = no-answer-1  (Regina adds this after a missed attempt)
  1. Wait4 hours.
  2. If/ElseTag tool-contacted present? → Yes: End. No: continue.
  3. Task“Attempt 2 — {{contact.name}}”  + Send SMS S4.
  4. Waituntil next morning (09:00).
  5. If/Elsetool-contacted? → No: Task “Attempt 3 + voicemail.”
  6. Wait2 days.
  7. If/Elsetool-contacted? → No: Pipeline move → Nurture; Add Tag tool-nurture-monthly; remove no-answer-1.
Goal / Exit   Tag tool-contacted added (Regina connects) → End & move Opportunity to Connected.
WF-4

TPB Member → BOSS Ascension

TriggerContact Tag Added = tpb-member  (fires on TPB purchase)
  1. PipelineMove Opportunity → TPB Member (Won #1).
  2. NotifyRegina: “{{contact.name}} joined TPB — onboard + set the BOSS clock.”
  3. Wait10 days (ascension timer; adjust 7–14).
  4. If/Else(optional) engaged/active? → if not, extend the wait or route to member-success first.
  5. PipelineMove → BOSS Opportunity; Task Regina/Closer: “Book BOSS call with {{contact.name}}.”
  6. Send EmailBOSS invite (the “Academy → BOSS: Your Options” angle) + optional SMS.
Goal / Exit   Tag boss-member → move Opportunity to BOSS Member (Won #2); End; hand to fulfillment.
WF-5

Exit / Kill-switch

TriggerContact Tag Added = tpb-member OR unsubscribed OR not-a-fit
  1. Remove from WorkflowWF-1 (Intake+Nurture), WF-2 (Hot), WF-3 (No-Answer).
  2. If/ElseIf not-a-fit → Pipeline move to Not a Fit, set lost-reason, remove tool-lead.
Purpose   Guarantees the cold sequences stop the instant someone converts or opts out. Build this so the other workflows never keep emailing a new member.
