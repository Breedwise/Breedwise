Build blueprint

System Spec

Data model, KPI formulas, permissions & integrations — the reference this interface is built from.

KPI formulas — Director

churn% = cancels_in_month ÷ active_at_month_start  ·  target < 3%
activation% = activated ÷ new_this_month  ·  target ≥ 80%
NPS = %promoters − %detractors  ·  target > 80
failed_pay% = members_w_failed ÷ active  ·  target < 3%

Activation — 6 binary steps

  • Onboarding call ≤ 48h
  • Strategy w/ Austin ≤ 7d
  • Vet strategy ≤ 14d
  • Joined & welcomed in community ≤ 7d
  • First community call week 1
  • First masterclass week 1

Activated = all six completed inside their windows. Done / not done — never a vibe.

KPI formulas — Community

week1_attend% = on both wk-1 calls ÷ new · ≥ 80%
ongoing_attend% = ≥1 call in 3-of-4 wks ÷ active · ≥ 70%
engagement = meaningful posts ÷ active ÷ wk · ≥ 1
triage = ack ≤ 24h ÷ issues · = 100%

KPI formulas — Accountability Leader

pod_attend% = pod on ≥1 call ÷ active pod
homework% = items done ÷ assigned per member
pod_churn% = pod cancels ÷ pod active at start

Ramp (d1–60): 2/3 → $100, 3/3 → $200. Ongoing (d61+): 3/3 → $200, else $0.
